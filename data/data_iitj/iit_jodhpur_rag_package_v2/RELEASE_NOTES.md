# Release Notes — IIT Jodhpur RAG Package V2 (Version 2.0.0)

**Release Date**: 2026-10-23  
**Target Consumer**: React RAG Chatbot  

## Key Enhancements in V2 Release
1. **Admissions Disentanglement**: Separated blended `general_admissions.md` into dedicated records for general regulations, non-degree students, M.Sc. seat matrix, MBA selection criteria, and placement procedures.
2. **Dual Degree Separation**: Disentangled M.Sc.–M.Tech. and M.Tech.–Ph.D. dual degrees into distinct canonical files.
3. **Fee Discrepancy Reconciliation**: Reconciled the B.Tech (₹1,00,000/sem) vs ITEP (₹50,000/sem) tuition variance with official citations in `academic_fees_and_scholarships.md` and `source_conflict_register.json`.
4. **Visitor Accommodation Isolation**: Extracted commercial visitor and guest hostel rates into a dedicated canonical document and dataset.
5. **Mathematics Programme Structure**: Partitioned Mathematics into B.S. curriculum, M.Sc. degrees, and Minor course matrix.
6. **Clean Rendering**: Fixed multi-line broken links, eliminated repeated `* * * *` bullets, and stripped scraped accordion `+` markers.
7. **Structured Duration Schema**: Normalized `academic_programmes.json` with typed duration dictionaries.
8. **V1 Historical Preservation**: V1 release preserved 100% untouched as a baseline.
