# IIT Jodhpur Document & Formatting Conventions (V2)

1. Canonical H1: Every Markdown document begins with exactly one H1 `# Title`.
2. Explicit Scope: Every document contains an introductory `## Scope` section defining domain boundaries.
3. Native Tables: All tabular facts are represented as standard Markdown tables and rendered as native Word `Table Grid` with blue header shading.
4. OpenXML Hyperlinks: Links are rendered as clickable OpenXML hyperlinks with blue underline styling.
5. Unified Provenance: Every document concludes with an official `## Official Sources and Provenance` block.
